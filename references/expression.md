## 1. 规则

本文件定义表达约束。以下规则作用于所有产物、文档、界面文案、代码注释；规则定义中需引用禁项原文，其余正文按规则 E-9 使用中性、专业表述。

| 编号 | 规则 |
| --- | --- |
| E-1 | 不出现辅助生成类标签 |
| E-2 | 不出现自动生成类标签 |
| E-3 | 不出现辅助生成类署名 |
| E-4 | 不出现自动生成类署名 |
| E-5 | 不出现辅助生成类声明 |
| E-6 | 不出现自动生成类声明 |
| E-7 | 不出现暗示生成类的字眼 |
| E-8 | 不出现"虚拟"字样 |
| E-9 | 使用中性、专业表述 |

说明：E-1..E-6 覆盖标签、署名、声明三类载体；E-7 覆盖任何暗示产物来源方式的措辞；E-8 覆盖禁用词；E-9 为正向要求，所有书写一律使用中性、专业表述。

## 2. 约束原文

以下为约束的原文规定（PRD 23.3）：

```
所有产物、文档、界面文案、代码注释：
不出现辅助生成类、自动生成类、暗示生成类标签、署名或声明。
不出现"虚拟"字样。
使用中性、专业表述。
```

## 3. 检查点

G9 交付门加入表达检查。违规即回退。

执行方式：

| 项 | 内容 |
| --- | --- |
| 检查位置 | G9 交付门（`references/gates.md`） |
| 检查范围 | 全部产物、文档、界面文案、代码注释 |
| 违规处理 | 回退至产出环节修改，重新过门 |
| 相关风险 | R-6（表达违规 → G9 检查）、R-16（违规即回退） |
| 验收标准 | 表达约束 0 违规（A-22），包括无暗示性字眼与禁用词 |

## 4. 与其他约束的关系

- 通用约束 U-4、U-5 为本约束在全局层的概括（`references/charter.md`）。
- 个人通用约束 IP-6 要求个人输出遵守表达约束（`references/individuals.md`）。
- G9 交付门否决权归 CCO；表达检查违规即回退，不进入交付。
